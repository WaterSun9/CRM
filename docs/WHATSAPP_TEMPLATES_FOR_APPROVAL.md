# WhatsApp messages - for the owner to approve

The CRM will send these 4 WhatsApp messages from Watersun Solar's number **92744 04398**. Meta must approve each one first. After approval, any change to the wording needs a fresh Meta review (usually within a day).

Please read them and reply **OK**, or send the changes you want.

**Bold** text changes for every message. The values shown are only examples.

---

## 1. Completion code (to the customer)

**When:** the technician has finished the work and taps "Work done - send code". The customer reads the code out to the technician, and the job closes.

**Note:** Meta writes this text itself, so it cannot be changed. We have turned off the line "For your security, do not share this code", because the customer *is* meant to tell the code to our technician.

> **482913** is your verification code.
>
> This code expires in 10 minutes.
>
> [ Copy code ]

---

## 2. Work completed (to the customer)

**When:** right after the code is accepted. The customer's button tap is saved on the complaint, for the office to see.

> Hello **Ramesh Patel**, technician **Suresh Thakor** has completed the work on your Watersun Solar service request no. **1023** today. Warranty status: **valid until 11 Oct 2031**. Please confirm if the problem is solved.
>
> [ Yes, solved ]  [ Not solved ]

The warranty part can also read "**ended on 11 Oct 2025**" or "**not recorded**".

---

## 3. New job for a vendor (to the vendor)

**When:** the office sends a customer to a vendor. The vendor still gets the same email as today. This WhatsApp is extra, and goes only if the vendor's mobile number is saved.

> Hello **Shree Ganesh Solar Services**, Watersun Solar has assigned you the delivery and installation work for a new customer. Customer: **Ramesh Patel**, mobile **9876543210**. Address: **12 Gayatri Society, Radhanpur, Patan**. System size (kW): **3.3**. File no. **1045**. Please log in to the Watersun vendor portal to see the full details. Thank you.

---

## 4. Quotation (to the customer)

**When:** a staff member or partner taps **WhatsApp** on a quotation in Quotation Maker. The quotation PDF comes attached, the same file as Download.

> [PDF] **Ramesh Patel.pdf**
>
> Hello **Ramesh Patel**, please find attached your Watersun Solar quotation **Quote-1023** for a **3.3** kW solar system. This quotation is valid until **11 Nov 2026**. For any questions, please call the contact number given in the quotation. Thank you.

**Note:** Meta may count this one as a *marketing* message. That costs about Rs 0.86 + GST per message, instead of about Rs 0.115 + GST. Words like "offer", "discount" or "best price" would make that certain, so this message has none.

---

## Optional: automatic reply

When someone writes to 92744 04398, the CRM can send one reply a day per person. This reply needs no Meta approval. If you want it, please send the exact text. For example:

> Thank you for your message to Watersun Solar. This number sends service and quotation updates only. For help, please call our office on **[office number]**.
